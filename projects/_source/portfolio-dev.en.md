## Problem
I needed my own technical calling card: a place to show my real stack (backend, AI agents, cloud) with a design that didn't feel generic or "AI-template-generated," and simple enough for me to maintain and update on my own without friction.

## Solution
A single-page static site built with **vanilla HTML, CSS, and JavaScript**, no build step or frameworks, deployed straight to **GitHub Pages** via GitHub Actions. The design follows a **monochrome brutalist** direction (techno-inspired): typography as the main character, no gradients or glow, with subtle animation (a mouse-reactive grid in the hero, project cards). On top of that I added a persistent **light/dark theme** and **bilingual es/en support** with JSON dictionaries, plus a small generator for per-project detail pages built from Markdown.

## Stack & Architecture
- Semantic HTML + CSS with custom properties for theming, no preprocessors.
- Vanilla JavaScript split into single-responsibility modules (`theme.js`, `i18n.js`, `index.js`) with zero runtime dependencies.
- Automatic deployment to GitHub Pages via GitHub Actions (`static.yml`), with no compile step.
- Project detail pages generated by a manually-run Node script (`scripts/build-projects.mjs`) that converts front-matter Markdown into static HTML.

## Challenges
The main challenge was keeping **zero build dependencies** while adding functionality that's usually handled by a framework (theming, i18n, per-project dynamic content). Solving that without compromising the visual style — avoiding duplicated CSS rules when introducing the light theme — meant leaning entirely on CSS custom properties instead of alternate stylesheets.
